# twitter-video-download

推特(X)视频下载器 —— 粘贴推文链接,一键解析视频直链,支持在线播放和多清晰度下载。

项目代码位于 [`twitter-video-downloader/`](twitter-video-downloader/) 目录,详细功能说明、
快速开始与 API 文档见 [twitter-video-downloader/README.md](twitter-video-downloader/README.md)。

```bash
cd twitter-video-downloader
pip install -r requirements.txt
python app.py
# 浏览器访问 http://127.0.0.1:5000
```
